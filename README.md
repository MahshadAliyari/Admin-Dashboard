# پنل صحنه — پنل مدیریت کاربران با JavaScript خام

مینی‌اپ فاز ۴ (تمرین ۱۱) هلدینگ صحنه: یک پنل مدیریت فارسی (RTL) که کاربران را از یک API عمومی دریافت می‌کند و نوشته‌ها، برگه‌ها، نظرها و رسانه را به‌صورت محلی مدیریت می‌کند.
بدون هیچ کتابخانه یا فریم‌ورکی؛ فقط HTML، CSS و JavaScript خام.

- **نسخه آنلاین:** `https://mahshadaliyari.github.io/Admin-Dashboard/` 
- **مخزن:** `https://github.com/MahshadAliyari/Admin-Dashboard`

## امکانات

| بخش | قابلیت‌ها |
|---|---|
| **پیشخوان** | آمار در یک نگاه، پیش‌نویس سریع، آخرین فعالیت‌ها، جدیدترین کاربران، وضعیت اتصال به API |
| **کاربران** | دریافت از API، افزودن/ویرایش/حذف/بازیابی، جستجوی زنده، فیلتر، مرتب‌سازی، صفحه‌بندی، نمودارها، اسلایدر مدیران |
| **نظرات** | تأیید، پاسخ، علامت‌گذاری هرزنامه، حذف، فیلتر بر اساس وضعیت |
| **نوشته‌ها / برگه‌ها** | CRUD کامل، جستجو و فیلتر وضعیت، انتشار/بازگشت به پیش‌نویس |
| **رسانه** | آپلود **تصویر، ویدیو و PDF**، پیش‌نمایش تصویر و پخش ویدیو، حذف، ماندگاری پس از رفرش |
| **گزارش‌ها** | آمار کاربران، نمودار جنسیت/شهر/سن، خروجی CSV |
| **تنظیمات** | عنوان سایت، تعداد آیتم در صفحه، اعلان‌ها، **تم تاریک/روشن**، بازنشانی داده‌ها |

### حالت‌های رابط (Loading / Error / Empty)
- **Loading:** هنگام دریافت کاربران، اسپینر نمایش داده می‌شود.
- **Error:** در صورت قطع شبکه یا پاسخ نامعتبر، پیام کاربرپسند و دکمه «تلاش مجدد» نمایش داده می‌شود. اپ بدون API هم کار می‌کند و کاربران محلی همچنان دیده می‌شوند.
- **Empty:** برای جستجو/فیلتر بدون نتیجه و لیست‌های خالی، پیام راهنما نمایش داده می‌شود.

## تکنولوژی‌ها

- HTML5 معنایی (`dialog`, `details`, ARIA)
- CSS خالص با Custom Properties، Grid/Flexbox و طراحی Mobile-first
- JavaScript ماژولار (ES Modules)
- Fetch API با `async/await` و `try/catch/finally`
- LocalStorage برای داده‌های ساده و IndexedDB برای فایل‌های رسانه

## اجرای پروژه

چون از ES Modules استفاده شده، فایل را با دوبار کلیک باز نکنید (`file://` کار نمی‌کند). یکی از این روش‌ها:

1. افزونه **Live Server** در VS Code ← کلیک راست روی `index.html` ← *Open with Live Server*
2. یا در ترمینال:
   ```bash
   npx serve .
   ```

## منبع داده (API)

کاربران از `js/api.js` دریافت می‌شوند. ساختار پاسخ بررسی می‌شود (`Array.isArray`) و در صورت خطای HTTP یا ساختار نامعتبر، خطا به لایه‌ی UI منتقل می‌شود.

هر کاربر به یک شکل یکسان نرمال‌سازی می‌شود (`normalizeUser`) تا کاربر سرور و کاربر محلی یکسان رفتار کنند.

## ذخیره‌سازی

| کلید | محتوا |
|---|---|
| `scene-local-users` | کاربران افزوده‌شده توسط مدیر |
| `scene-deleted-ids` | شناسه‌ی کاربران حذف‌شده (حذف نرم) |
| `scene-server-edits` | ویرایش‌های کاربران سرور |
| `scene-recent-searches` | ۵ جستجوی اخیر |
| `scene-comments` / `scene-posts` / `scene-pages` | محتوای پنل |
| `scene-media` | **متادیتا**ی رسانه (نام، حجم، نوع) |
| `scene-settings` / `scene-theme` | تنظیمات و تم |

**چرا IndexedDB برای رسانه؟** LocalStorage حدود ۵ مگابایت ظرفیت دارد و فقط متن ذخیره می‌کند؛ ویدیو چند ده مگابایت است. بنابراین خود فایل‌ها (Blob) در IndexedDB نگه‌داری می‌شوند و فقط متادیتای آن‌ها در LocalStorage است. اگر IndexedDB در دسترس نباشد (مثلاً حالت خصوصی بعضی مرورگرها)، به کاربر پیام خطا نشان داده می‌شود و فایل اضافه نمی‌شود.

### محدودیت‌های آپلود رسانه

| نوع | فرمت‌های مجاز | حداکثر حجم |
|---|---|---|
| تصویر | `image/*` | ۱۰ مگابایت |
| ویدیو | MP4، WebM، OGG، MOV | ۱۰۰ مگابایت |
| سند | PDF | ۱۰ مگابایت |

نوع فایل از روی `file.type` بررسی می‌شود، نه فقط پسوند نام آن.

## امنیت و کیفیت کد

- تمام داده‌ی کاربر قبل از ورود به قالب‌های HTML با `escapeHtml` پاک‌سازی می‌شود. متن‌های ساده با `textContent` نوشته می‌شوند.
- خروجی CSV در برابر **CSV Injection** (مقادیری که با `= + - @` شروع می‌شوند) ایمن شده است.
- همه‌ی خواندن‌ها/نوشتن‌های ذخیره‌سازی داخل `try/catch` هستند و داده‌ی خراب به مقدار پیش‌فرض برمی‌گردد.
- اعتبارسنجی سمت کاربر برای همه‌ی فرم‌ها (ایمیل، سن، عنوان، جستجو) با پیام خطای زیر فیلد.
- جستجو با `debounce` اجرا می‌شود.

## دسترسی‌پذیری و ریسپانسیو

- لینک «پرش به محتوای اصلی»، برچسب‌های ARIA، مدیریت فوکوس و پشتیبانی از `Escape`
- احترام به `prefers-reduced-motion` (پخش خودکار اسلایدر در این حالت خاموش است)
- پخش خودکار اسلایدر با هاور یا فوکوس متوقف می‌شود
- طراحی Mobile-first با نقاط شکست `40rem / 56rem / 64rem / 80rem`؛ جدول کاربران در موبایل به کارت تبدیل می‌شود
